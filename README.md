# 🦀 OxideCode — a pure-Rust native code editor

OxideCode is a desktop code editor written **entirely in Rust**. No JavaScript,
no webviews, no Electron: the UI is rendered with [`egui`](https://www.egui.rs/)
(via `eframe`), which is itself 100% Rust and builds for **macOS, Linux and
Windows** from this single codebase.

## Features

- **Tabbed editor** with syntax highlighting for 23 built-in core languages —
  Rust, Python, JavaScript, TypeScript, Go, C, C++, C#, Java, Kotlin, Swift,
  Ruby, PHP, HTML, CSS, JSON, TOML, YAML, Markdown, Shell, SQL, XML and
  Dockerfile — all tokenized by a hand-written pure-Rust scanner.
- **Local diff view** (`📊 Diff` button or palette): a split pane comparing the
  current buffer against the **last saved state**, with `−removed / +added`
  counts and one-click *Revert to saved*.
- **Write everything in Rust**: `File → New Rust Project…` scaffolds a real
  binary or library crate (Cargo.toml + src + README + .gitignore) generated by
  the app itself.
- **Real toolchain integration**: Run menu / terminal panel execute actual
  `cargo check / clippy / test / run / build / fmt` processes; `cargo check`
  JSON output is parsed into the **Problems** panel with click-to-jump, and
  `rustfmt` can run automatically on save for `.rs` files.
- **Integrated terminal** running real OS processes (`sh -c` / `cmd /C`),
  search-across-workspace, file explorer, command palette (`⌘/Ctrl+Shift+P`),
  5 themes, adjustable font/tab size, persistent config.

## Build

Prerequisite: a Rust toolchain (`rustup`, stable ≥ 1.85).

```sh
cargo build --release
```

### macOS (priority platform)

```sh
cargo build --release
./target/release/oxide-code
```

No extra dependencies — Metal/Quartz backends ship with the OS.

### Linux (priority platform)

Install the X11/Wayland client headers once:

```sh
sudo apt install libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev \
  libxkbcommon-dev libssl-dev
cargo build --release
./target/release/oxide-code
```

### Windows

```powershell
cargo build --release
.\target\release\oxide-code.exe
```

No extra dependencies — DirectX/Win32 backends ship with the OS.

## Test / lint

```sh
cargo test
cargo clippy --all-targets
cargo fmt --check
```

## Layout

| Path | What |
| ---- | ---- |
| `src/main.rs` | Entry point (`eframe::run_native`) |
| `src/app.rs` | App state, menus, status bar, command palette, dialogs |
| `src/ui_editor.rs` | Tabs, highlighted editor, split-pane diff view |
| `src/ui_sidebar.rs` | Explorer, search, languages/tools, settings |
| `src/ui_bottom.rs` | Problems, terminal, output panels |
| `src/buffer.rs` | Text buffer + last-saved snapshot |
| `src/diff.rs` | Bounded Myers line diff |
| `src/highlight.rs` | Tokenizer + egui layout builder |
| `src/languages.rs` | 23 core language definitions + templates |
| `src/diagnostics.rs` | `cargo check` JSON/human parsers |
| `src/terminal.rs` | Background process runner |
| `src/project.rs` | Workspace tree, I/O, Rust project scaffolding |
| `src/theme.rs` | 5 themes + egui visuals |
| `.github/workflows/build.yml` | macOS / Linux / Windows CI |
